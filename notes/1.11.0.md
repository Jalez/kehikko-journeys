- **Change part of a step.** An agent can now change just one thing about a step, such as the objective it sits under, its phase or its issue. Everything else about the step stays as written.
- **Restructure in one go.** Several steps can be changed together, so a flat journey becomes a tree in one call. If any change is refused, none of them is written.
- **/journey refines flat journeys.** When a journey is already a flat list of steps, /journey keeps those steps and builds the tree around them. It also says what to do when a Claude session started before the module was updated.
